# CineVault Frontend Source

এটি Admin Panel ছাড়া frontend source। `client/src/videoLinks.ts` edit করে sponsor ও YouTube link বদলানো যাবে।

Install ও static build-এর জন্য project root থেকে `pnpm install` এবং `pnpm exec vite build --base=./ --outDir dist` ব্যবহার করুন। GitHub Pages-এ publish করার জন্য ready-made build নিতে `cinevault-github-pages.zip` ব্যবহার করা সহজ।
